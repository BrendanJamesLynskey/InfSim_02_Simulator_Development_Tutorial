# LLM Inference Simulators 02 — Simulator Development: A Hands-On Tutorial

Build a discrete-event simulator from an empty file: the event queue, simulated time, processes, resources and probes; then SimPy idioms, how to structure a simulator so it survives contact with architects, modelling buses, memories and pipelines, and making the simulator itself fast.

Topics: Discrete-event simulation, SimPy, Event queue, Resources, Determinism, Performance.

**Live site:** https://brendanjameslynskey.github.io/InfSim_02_Simulator_Development_Tutorial/

Part of the [LLM Inference Simulators series](https://github.com/BrendanJamesLynskey/LLM_Hub_Inference_Simulators). Companion code: [Disaggregated_Inference_Sim](https://github.com/BrendanJamesLynskey/Disaggregated_Inference_Sim).
